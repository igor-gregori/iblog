# Como um modelo é treinado?

O segundo post da série "IA para quem já programa": o pré-treino, o ajuste fino e o aprendizado por reforço, e o
que cada etapa explica no trabalho com agentes de código.

É um post só de texto: não tem análise em Python nem `dados.json`. A página é `pagina/App.tsx`. O modelo de
brinquedo da parte 2 conta tokens num texto escrito para a página (`pagina/corpus.ts`, `pagina/brinquedo.ts`);
`testes/brinquedo.test.ts` confere o que o texto diz sobre ele.

O plano da série está em [`planos/serie-ia.md`](../../planos/serie-ia.md).
