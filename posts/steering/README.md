# Steering: o que essa palavra quer dizer, afinal?

O nono post da série "IA para quem já programa": os três usos da palavra steering (corrigir o agente enquanto ele
trabalha, os arquivos de regras do Kiro e a mudança nas ativações do modelo) e como saber de qual alguém está falando.

É um post só de texto: não tem análise em Python nem `dados.json`. A página é `pagina/App.tsx`.
